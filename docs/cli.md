# 命令行接口

`vasletd` 中的 `d` 表示 daemon，是后台配置服务。`vasletctl` 是用于查询、修改和同步配置的命令行工具；这些配置操作尚未实现。

当前两者只提供骨架入口：

| 参数 | 行为 | 退出码 |
| --- | --- | --- |
| `--help` | 输出使用说明 | 0 |
| `--version` | 输出版本 | 0 |
| 无参数或其他参数组合 | 向标准错误报告功能尚未实现 | 1 |

`vasletctl --version` 通过客户端动态库的 `vaslet::Version()` 获取版本，用于验证链接。
`vasletd` 尚不会启动配置服务。配置操作、配置文件路径及服务运行参数待实现。
