# 编译产物体积

目标为服务端、客户端动态库和 CLI 的编译产物合计小于 100 KB。
当前只有最小骨架；骨架测量不能证明完整功能满足目标。

使用 `docs/building.md` 中的发布安装流程，再运行：

```sh
sh scripts/measure-size.sh build/target-release/stage
```

脚本合计三个实际文件的字节数，不重复计入符号链接；头文件、文档和测试不计入。
可通过第二个参数指定库目录，例如 `lib64`。
脚本还通过 `readelf` 或 `otool` 列出直接动态依赖；它不解析或累计全部依赖的文件大小，
没有可用工具时会提示。交叉编译产物应使用目标 SDK 工具核查依赖。

验收报告应记录：

- 目标架构、操作系统及工具链版本。
- 源码版本、构建类型、编译与链接选项、符号剥离方式。
- 三个编译产物各自的字节数和合计。
- 新增运行时依赖、设备已有依赖及各自的统计方式。

100 KB 的字节口径及新增依赖是否计入预算尚待确定，所以脚本目前只报告字节数，
不作达标判定。运行时内存占用单独测量。当前未发布目标设备的体积或性能结果。
